# Glossar {#sec-glossar .appendix bb="ech-0003-bb-glossar" typ="concept" original-seite="34"}

In diesem Teil des Glossars werden jene Begriffe aufgeführt, welche im vorliegenden Dokument Anwendung finden. Um den Lesefluss zu erleichtern wird im Text jeweils nur der Begriff verwendet und hier im Glossar zusätzlich die vollständig korrekte Bezeichnung geführt.

|   |   |
|:------------------|:--------------------------------------------------------------|
| Geschäftsstelle | Geschäftsstelle des Vereins eCH |
| Expertenausschuss | Expertenausschuss des Vereins eCH |
| Fachgruppe(n) | Fachgruppe(n) des Vereins eCH |
| Referentinnen und Referenten | Referentinnen und Referenten des Expertenausschusses |
| Vorstand | Vorstand des Vereins eCH |
| Webseite | Webseite des Vereins eCH |

In diesem Teil des Glossars sind jene Begriffe aufgeführt, welche in den als Beilagen definierten Vorlagen Verwendung finden und dadurch einen eindeutigen Bezug zu diesem Standard herstellen. Sie werden auch als Metadaten verwendet.

<!-- Die Einträge gehören zum groben Baustein, nicht zur Klausel davor (E15). -->

::: {bb="ech-0003-bb-reservierte-begriffe-anpassen" typ="requirement" original-seite="35"}
[MUSS] Diese reservierten Begriffe dürfen in den Vorlagen nur zusammen mit der Überarbeitung dieses Standards angepasst werden.
:::

|   |   |
|:------------------|:--------------------------------------------------------------|
| eCH-Nummer | gemäss Kapitel [-@sec-zuteilung-ech-nummer]{.mit-titel} |
| Kategorie | Die Kategorie entspricht der Antragsform gemäss Kapitel -@sec-anwendungsgebiet. |
| Reifegrad | gemäss Kapitel [-@sec-reifegrad]{.mit-titel} |
| Version | Die Version entspricht der Versionsnummer gemäss Kapitel [-@sec-versionierung]{.mit-titel}. |
| Ausgabedatum | Datum, welches die Version näher spezifiziert (vgl. dazu Ausführungen unter den Kapiteln [-@sec-versionierung]{.mit-titel} und [-@sec-formale-aenderungen]{.mit-titel}). |
| Ersetzt Version | Versionsnummer der Dokumentversion, die mit dem neuen Dokument ersetzt wird (vgl. auch Kapitel [-@sec-versionierung]{.mit-titel}). |
| Status | gemäss Kapitel [-@sec-bearbeitungsstatus]{.mit-titel} |
| Beschluss am | Datum, an welchem das zuständige Gremium den Beschluss gefällt hat (Status «Genehmigt», «Aufgehoben» oder «Sistiert»). |
| Überprüft am | Datum, an welchem die letzte Überprüfung gemäss Kapitel [-@sec-ueberpruefung]{.mit-titel} stattgefunden hat. |
| Voraussetzungen | gemäss Kapitel [-@sec-voraussetzungen-abhaengigkeiten]{.mit-titel} |
| Beilagen | Beilagen, welche zu einem Dokument gehören und gleichzeitig publiziert sind. |
| Sprachen | Sprache(n), in denen das Dokument publiziert ist (vgl. auch Kapitel [-@sec-publikation]{.mit-titel}). |
