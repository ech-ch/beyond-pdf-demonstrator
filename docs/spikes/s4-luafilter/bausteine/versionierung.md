## Versionierung {#sec-versionierung bb="ech-0003-bb-versionierung" typ="rule"}

::: {#bb-zielversion .baustein typ="requirement"}
[MUSS] Bei der Versionierung sämtlicher Antragsformen gilt das Prinzip der Zielversion. Das heisst ein Dokument behält über sämtliche Prozessschritte die gleiche Versionsnummer. Diese wird durch den Bearbeitungsstatus (siehe Kapitel 7.5) sowie das Ausgabedatum weiter spezifiziert.
:::

::: {#bb-semver .baustein typ="requirement"}
[MUSS] Die Struktur erfolgt gemäss «Semantic Versioning»[SemVer]. …
:::

Die formale Syntax für das von eCH verwendete Schema ist Anhang F unten zu entnehmen.

::: {#bb-schema-eigene-version .baustein typ="requirement"}
[MUSS] Besteht nebst einem eCH-Dokument auch ein Schema, so erhalten das Dokument und das Schema je eine eigene, unabhängige Versionsnummer.
:::
